¿por qué esta tabla se puede llamar «genérica»? ¿Qué tendría que cambiar para mostrar alumnos en lugar de productos?

Se llama genérica porque puede mostrar cualquier tipo de datos según las columnas y filas que recibe y Para mostrar alumnos, cambiarían las columnas y los datos que se le pasan. La tabla seguiría igual.

describan el contrato de su componente en tres partes: qué recibe, qué avisa y qué guarda adentro: 
Recibe: los valores mínimo, máximo e inicial.
Avisa: emite cantidad-cambiada con el nuevo valor al pulsar mas o menos.
Guarda adentro: la cantidad actual, manteniéndola entre el mínimo y el máximo.
